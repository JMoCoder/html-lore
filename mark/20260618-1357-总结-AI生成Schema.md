# 总结：AI生成Schema

**时间**：2026-06-18 13:57 JST
**状态**：待实现

> **使用说明**：本文件是 AI HTML 生成 v2 的 schema 草案，面向后续 `generation_v2/schemas.py` 的 Pydantic/dataclass 实现。字段名建议优先使用 snake_case。

---

## 通用约定

- 所有模型输出必须是结构化 JSON。
- 所有 list 字段默认空数组。
- 所有 dict 字段默认空对象。
- 所有字符串字段默认空字符串。
- Agent 输出进入 `GenerationState` 前必须校验 schema。
- schema 失败不由 Runtime 修业务内容，只触发节点重试或失败。

## GenerationInput / 生成输入

```text
GenerationInput
  - instruction: str
  - filename: str
  - content_type: str
  - theme: str
  - target_use: str
  - style_preference: str
  - reference_style: str
  - reference_file_name: str
  - reference_file_type: str
  - reference_file_size: int
  - target_collection: str = "inbox"
  - source_type: str = "ai_generated"
```

约束：

- `target_collection` 第一版默认 `inbox`。
- `reference_style` 可取 `default` / `file`。

## ParsedDocument / 解析后的文档

```text
ParsedDocument
  - source_files: list[SourceFile]
  - plain_text: str
  - outline: list[OutlineItem]
  - images: list[DocumentImage]
  - links: list[DocumentLink]
  - tables: list[DocumentTable]
  - style_hints: list[StyleHint]
  - warnings: list[ParseWarning]
```

子结构：

```text
SourceFile
  - filename: str
  - content_type: str
  - size: int
  - role: str  # material | style_reference

OutlineItem
  - level: int
  - title: str
  - text: str

DocumentImage
  - alt: str
  - description: str
  - source: str

DocumentLink
  - text: str
  - url: str
  - source: str

DocumentTable
  - title: str
  - headers: list[str]
  - rows: list[list[str]]

StyleHint
  - kind: str
  - value: str
  - confidence: float

ParseWarning
  - code: str
  - message: str
  - severity: str
```

约束：

- `plain_text` 可为空，但如果为空必须有 warning。
- `warnings` 不触发用户补材料交互，只供 Agent 保守处理。

## RequirementBrief / 需求简报

```text
RequirementBrief
  - user_goal: str
  - target_use: str
  - audience: str
  - output_type: str
  - source_summary: str
  - must_include: list[str]
  - should_avoid: list[str]
  - constraints: list[str]
  - style_preferences: list[str]
  - reference_style_files: list[str]
  - success_criteria: list[str]
  - uncertainty: list[str]
```

约束：

- `user_goal` 必填。
- `success_criteria` 至少 3 条，供 Verifier 使用。
- `uncertainty` 可为空；不触发用户补充材料流程。

## PlanDraft / 方案草案

```text
PlanDraft
  - page_goal: str
  - information_architecture: str
  - section_plan: list[SectionPlan]
  - content_strategy: str
  - visual_strategy: str
  - tool_needs: list[ToolNeed]
  - execution_checklist: list[ChecklistItem]
  - risk_points: list[str]
  - verification_targets: list[str]
```

子结构：

```text
SectionPlan
  - id: str
  - title: str
  - purpose: str
  - source_refs: list[str]
  - expected_content: list[str]

ToolNeed
  - tool_name: str
  - reason: str
  - priority: str  # low | medium | high
  - optional: bool

ChecklistItem
  - id: str
  - title: str
  - owner: str
  - status: ChecklistStatus
  - acceptance: str
  - notes: str
```

约束：

- `section_plan` 不应为空。
- `execution_checklist` 至少覆盖内容、样式、HTML、验证、安全。

## ContentDraft / 内容草稿

```text
ContentDraft
  - title: str
  - subtitle: str
  - summary: str
  - sections: list[ContentSection]
  - key_points: list[str]
  - callouts: list[Callout]
  - tables: list[DocumentTable]
  - quotes: list[Quote]
  - references_used: list[str]
  - omitted_items: list[str]
```

子结构：

```text
ContentSection
  - id: str
  - title: str
  - body: str
  - bullets: list[str]
  - source_refs: list[str]

Callout
  - kind: str  # note | warning | insight | summary
  - title: str
  - body: str

Quote
  - text: str
  - source: str
```

约束：

- 不包含 CSS。
- 不包含 HTML。
- `sections` 应覆盖 `PlanDraft.section_plan`。

## StyleBrief / 样式简报

```text
StyleBrief
  - style_goal: str
  - design_mode: DesignMode
  - reference_sources: list[str]
  - color_palette: list[ColorToken]
  - typography: TypographySpec
  - layout_system: str
  - component_style: str
  - density: str
  - visual_hierarchy: str
  - interaction_level: str
  - responsive_rules: list[str]
  - avoid_styles: list[str]
  - implementation_notes: list[str]
```

子结构：

```text
ColorToken
  - name: str
  - value: str
  - usage: str

TypographySpec
  - font_family: str
  - heading_style: str
  - body_style: str
  - scale: str
```

约束：

- 不做像素级复刻。
- 必须考虑移动端可读。
- `avoid_styles` 应包含用户明确不要的风格。

## HtmlDraft / HTML 草稿

```text
HtmlDraft
  - html: str
  - assets: list[AssetRef]
  - css_notes: list[str]
  - js_notes: list[str]
  - render_assumptions: list[str]
  - accessibility_notes: list[str]
  - responsive_notes: list[str]
```

子结构：

```text
AssetRef
  - kind: str
  - src: str
  - description: str
```

约束：

- `html` 必须是完整 HTML 文档或项目约定可渲染片段，第一版建议完整 HTML。
- 不允许 HTML Coder 改变事实和核心结构。
- 如果内容不足，应返回上游，不应胡编。

## ValidationReport / 需求验证报告

```text
ValidationReport
  - ok: bool
  - score: float
  - checked_items: list[CheckedItem]
  - issues: list[ValidationIssue]
  - missing_parts: list[str]
  - unsupported_claims: list[str]
  - style_mismatch: list[str]
  - structure_mismatch: list[str]
  - route_back_to: str
  - retry_instruction: str
```

子结构：

```text
CheckedItem
  - id: str
  - title: str
  - passed: bool
  - notes: str

ValidationIssue
  - code: str
  - message: str
  - severity: str
```

约束：

- `route_back_to` 只能是允许节点：Planner / Content Writer / Style Designer / HTML Coder / Tool Executor / none。
- `ok = false` 时必须有 `issues` 或 `missing_parts`。

## SafetyReport / 安全审查报告

```text
SafetyReport
  - ok: bool
  - risk_level: RiskLevel
  - issues: list[SafetyIssue]
  - blocked_items: list[str]
  - warnings: list[str]
  - route_back_to: str
  - requires_user_confirmation: bool
```

子结构：

```text
SafetyIssue
  - code: str
  - message: str
  - severity: str
  - location: str
```

约束：

- `risk_level = blocked` 时 `ok = false`。
- 高风险外链、危险 script、iframe/form/tracking 默认 blocked。

子结构：

NoteMetadataProposal
