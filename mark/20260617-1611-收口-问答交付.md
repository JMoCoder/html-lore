# 收口：知识库问答正式交付

**时间**：2026-06-17 16:11
**状态**：已完成

---

## 需求背景

知识库问答从最初的 runtime 形态，逐步收敛到 LangGraph 优先的多智能体编排，并补齐了上下文恢复、外部搜索、来源引用、安全门控和静态 demo 展示。此处需要正式收口，作为 1.0.0 交付版本的项目记忆。

## 解决方案

采用 LangGraph-first 的问答编排，runtime 作为降级路径保留。问答链路由上下文解析、路由规划、搜索规划、证据整理、答案生成、Verifier、Reviewer 与 Finalizer 组成；外部搜索使用 Tavily / Brave 可选链式回退，未配置时仍能最低可用运行。

## 实施细节

- 新增搜索规划与证据评估节点。
- 新增 Tavily -> Brave -> disabled 外部搜索链。
- 统一来源引用为可点击 pill。
- 调整前端问答文案为“拓展 / 研究”。
- 更新 README、CHANGELOG、demo manifest 与 demo 文档页。
- 发布版本号统一抬升到 `1.0.0`。

## 遇到的问题

- 早期检索与回答阶段混用了较多硬编码逻辑，导致内容拓展与上下文继承不稳定。
- demo 与正式服务的版本号、摘要文案曾经分叉。
- 本地运行时曾生成 `meta/` 等无关产物，需要与正式提交隔离。

## 最终结果

知识库问答已作为正式交付版本收口，外部搜索与来源展示完成链路化，文档和 demo 示例页已同步到 1.0.0 语义。

## 值得注意

- 以后新增 AI 能力时，优先更新文档、demo 和版本号链路。
- demo 只负责静态展示，不承载真实业务执行。
- `meta/` 属于运行时生成物，不应混入正式版本提交。
