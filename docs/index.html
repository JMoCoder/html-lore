文件即真源

没有 SQL，没有向量库。正文是 HTML，元数据是 YAML sidecar。备份就是拷目录，迁移就是拷文件。

01

正文是 HTML

每篇笔记是一个独立 .html。用浏览器打开、用任何静态服务器托管、用编辑器改。它永远可读。

02

元数据是 YAML

标题、摘要、集合、标签、收藏、归档写在同名 .yml 里。纯文本，可 diff，可版本管理。

03

没有数据库

不跑 Postgres，不建索引。磁盘目录就是库。换机器、换容器，把 data/ 拷过去就完了。

一个工作台，管所有 HTML

保存即生效

写盘后 iframe 立刻刷新。你看到的就是磁盘上的文件，没有中间状态。

保存前安全预检

每次保存先扫描；会影响安全分享的改动先提示，由你决定写不写。

写回核对

写完读回比对，不一致就报错。不会静默写坏一篇笔记。

安全分享，两种模式

每条链接一个 token，磁盘只存哈希。过期、撤销、原文归档后，对外就是 404。

safe消毒静态

去掉脚本、表单、iframe 和危险标签，只留可读内容。过不了扫描会自动生成一份消毒副本再分享。

适合：从第三方收藏的 HTML。来源不可控，消毒后再分享才放心。

  • 脚本 / 内联事件 / javascript: 一律剥离
  • 密钥形态文本拦截或脱敏
  • 默认模式，始终可用

interactive互动沙箱

按原文跑，iframe 只给 allow-scripts，不给 same-origin。过不了安全扫描就直接拒绝，不做副本。

适合：自己生成、内容可控的 HTML。知根知底，保留交互原样分享。

  • 保留交互，但关在沙箱里
  • 私网引用需二次确认
  • 可用环境变量整体关掉

一个容器，跑在你自己的机器上

独立 Docker 服务，默认端口 3000。和冻结的 1.x 并行，不替换、不共用数据目录。

# 2.0 独立服务
git clone https://github.com/JMoCoder/html-lore.git
cd html-lore && cp .env.example .env
docker compose up -d --build
 
# 从 1.x 拷文件库（不是 dump）
npm run migrate:1x -- /srv/v1/data ./data
