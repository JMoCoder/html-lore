文件即真源

没有 SQL，没有向量库。正文是 HTML，元数据是 YAML sidecar。备份就是拷目录，迁移就是拷文件。

01

正文是 HTML

每篇笔记是一个独立 .html。用浏览器打开、用任何静态服务器托管、用编辑器改。它永远可读。

02

元数据是 YAML

标题、摘要、集合、标签、收藏、归档写在同名 .yml 里。纯文本，可 diff，可版本管理。

03

没有数据库

不跑 Postgres，不建索引。磁盘目录就是库。换机器、换容器，把 data/ 拷过去就完了。

一个工作台，管所有 HTML

导入、整理、阅读、编辑。界面只做这一件事，不做问答，不做生成。

READING · ★

Offline-First 阅读体验

PWA 壳缓存策略与收藏卡片。

筛选与排序

资料库视图、集合、标签（任一/全部）、只看收藏、六种排序。全部在浏览器里即时完成。

阅读与编辑

iframe 沙箱读原文；CodeMirror 改源码，或可视化改文字和样式。元数据随改随存。

归档与删除

归档锁定编辑、移出主视图；永久删除必须先归档。不会误删。

安全分享，两种模式

每条链接一个 token，磁盘只存哈希。过期、撤销、原文归档后，对外就是 404。

safe消毒静态

去掉脚本、表单、iframe 和危险标签，只留可读内容。过不了扫描会自动生成一份消毒副本再分享。

  • 脚本 / 内联事件 / javascript: 一律剥离
  • 密钥形态文本拦截或脱敏
  • 默认模式，始终可用

interactive互动沙箱

按原文跑，iframe 只给 allow-scripts，不给 same-origin。过不了安全扫描就直接拒绝，不做副本。

  • 保留交互，但关在沙箱里
  • 私网引用需二次确认
  • 可用环境变量整体关掉

一个容器，跑在你自己的机器上

独立 Docker 服务，默认端口 3000。和冻结的 1.x 并行，不替换、不共用数据目录。

# 2.0 独立服务
git clone https://github.com/JMoCoder/html-lore.git
cd html-lore && cp .env.example .env
docker compose up -d --build
 
# 从 1.x 拷文件库（不是 dump）
npm run migrate:1x -- /srv/v1/data ./data

2.0 明确不做

比 1.x 简化是刻意的。砍掉的部分，写在明处。

没有 AI

不生成 HTML，不做知识库问答，不接模型。1.x 的 AI 密钥和索引不会被带进 2.0。

没有应用内登录

默认假设你在反代层做鉴权。只有显式配置，才会出现 1.x 那套账号页。

不替换 1.x

2.0 是新容器、新目录、新端口。1.x 冻结并行；迁过来等于放弃问答和生成。

不是离线库

PWA 只缓存壳和静态资源。笔记正文、分享页、API 始终走网络。
