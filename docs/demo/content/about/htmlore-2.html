HTMlore 2.0

自托管 HTML 知识工作台。笔记是磁盘上的 HTML + YAML，没有数据库，也没有应用内登录或 AI。

还做什么

  • 导入 HTML，用集合 / 标签 / 收藏 / 归档筛选
  • 在阅读页看原文，改元数据和源码
  • 安全分享：消毒副本或沙箱 iframe
  • 独立 Docker 服务 html-lore-v2，默认端口 3000

不再做什么

  • 知识库问答、HTML 生成、AI 侧栏和模型设置
  • 把工作台登录当成产品能力（公网用反代）
  • 原地替换正在运行的 1.x 容器或共用其 data/

分支

维护线是 main / tag v2.0.5。1.x 冻结在 legacy / v1.2.5。迁资料库用 npm run migrate:1x 拷贝文件，不要两套进程写同一卷。

这个页面是 GitHub Pages 上的静态预览：可以点卡片、筛选、阅读，不能导入、保存或分享。
